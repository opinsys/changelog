Opinsys OS releases and changes

The following changelog lists Opinsys OS (operating system) releases and changes after the previous version. In addition to the described changes, each release contains the latest security related software updates (for example, updates to the latest web browsers). 

  

## O2620 – Dysprosium {#opinsys-os-opinsys-bookworm-2026-05-11-094629-amd64}

update.

for creating Abitti 2 USB media has been added. In addition,
the device can now also write other .iso and .img disk images.

- No separately listed technical changes.


## O2616 – Curium {#opinsys-os-opinsys-bookworm-2026-04-13-071631-amd64}

- 
The IP range of the Abitti 2 exam server has been expanded so that
the server can provide IP addresses to a larger number of student
devices during the day. As a result of this change, the exam network
IP address will change during the update, which requires requesting
a new address for the exam server from Naksu 2.


- 
The Opinsys exam server can now be connected to the Koejakaja
service also in a so-called open network where the server does not
act as a DHCP server. Previously this was only partially possible
and did not persist across device reboots. Going forward, the
functionality can be enabled via device management using the
setting: `puavo.ers.mode abitti2server_examnet_unmanaged`.


- 
On fatclients, Google Chrome and Firefox browser updates are now
applied on the server during nighttime only. This prevents situations
where a browser update interrupts an active session or causes
browser instability.


- 
Support for Abitti 2 functionality has been added to the Laptop
settings tool.


- 
The local Nextcloud on the Opinsys boot server has been updated
to version 32.0.8.


### Known issues

- No known issues.

### Technical changes

- Add: Ability to enable GRUB password protection.
- Add: Munin configuration for Abitti exam servers and ability to monitor load metrics.
- Add: Packages nodejs and npm.
- Add: Support for devel branch puavo-pkg packages.


## O2611 – Broom {#opinsys-os-opinsys-bookworm-2026-03-09-100004-amd64}

- 
After this update it is possible to install the Abitti 2 candidate
application provided by the Finnish Matriculation Examination Board
(YTL) on upper secondary school laptops. Technically the application
is the Abitti 2 candidate USB environment integrated onto the
computer’s internal storage. The installed version is defined in the
customer organisation settings and Opinsys upper secondary school
laptops will normally receive the latest available version of the
application. Two versions of the application may exist on the device
at the same time, providing flexibility between student laptops and
the version used on the exam server. The application updates
automatically in the background and normally requires no actions
from school staff or students. If the school network allows device
to device communication, laptops can share the Abitti 2 installation
with each other which speeds up updates and reduces internet
bandwidth usage. After installation the Abitti 2 candidate
application appears in the computer’s start menu. The application
is launched in the same way as with the previous Abitti 1 system
from the boot menu shown when the computer is started or restarted.


- 
Exam mode now works normally again with newer Abitti 2 exam
server versions.


- 
The operation of the Opinsys Abitti 2 exam server has been improved
as part of the system update.


### Known issues

- No known issues.

### Technical changes

- OTPClient is shown only on personally managed laptops.
- Abitti 2 exam server component ktp-controller updated to version 0.3.0.


## O2607 – Aktiinium {#opinsys-os-opinsys-bookworm-2026-02-13-102438-amd64}

- 
Joining Abitti exams in exam mode has been updated to match
changes in the Abitti 2 system. Previously, joining was only
possible using a two-part exam server name (e.g. Kamala
Trumpetti). It is now also possible to use a single-part Abitti 2
server name (e.g. liikuntasali) as well as the full domain name
(e.g. ktp1.999.koe.abitti.net). The change improves compatibility
with the new Abitti 2 exam server and makes joining easier with
different naming conventions.


- 
The Join exam user interface in exam mode has been renewed.
Joining methods (Abitti 2, URL exams and Next-Exam) are now
separated into their own tabs, and only one method is visible at
a time for clarity. Each tab includes a unified "Join exam"
button. The renewal improves clarity and makes it easier to
select the correct joining method during an exam.


- 
The OTPClient two-factor authentication application has been
added to the Utilities menu. The application can be used to
manage TOTP-based one-time codes for services requiring
two-factor authentication.


- 
The Advanced network configuration application
(nm-connection-editor) has been added to the Utilities menu.
The application allows detailed management and modification of
network connections.


- 
Support for Koejakaja server functionality has been added to the
Abitti 2 exam server environment.


### Known issues

- No known issues.

### Technical changes

- Kernel updated to version 6.1.0-42 (Debian Bookworm).
- NVIDIA driver updated.
- Docker versions aligned with YTL Linux environment.

## O2533 - Skandium {#opinsys-os-opinsys-bookworm-2025-08-15-065628-amd64}

- 
On Opinsys devices, the so-called ```Exam Mode``` is now enabled by default. It is designed for taking digital exams in a locked environment. In this mode, the user’s normal desktop, free web browsing, and access to personal files are disabled.  
Exam Mode is visible and available via the ```Exam Mode``` button in the Menu. It can be used for both Abitti 2 exams and other online exams, for example through Moodle, Google Forms, or publishers’ exam platforms.  


- 
Locked Exam Mode can be used for taking Abitti 2 exams, Next-Exam assessments, or exams created with Google Forms or publishers’ online platforms.  
The process of joining an exam has been redesigned: when Exam Mode is launched from the application menu, a dedicated "Join Exam" window is shown. From there, a student can join an Abitti 2 exam directly with the exam code or connect to any URL-based exam.  
Note: Locked Exam Mode is not an officially approved way by the Matriculation Examination Board (YTL) to participate in Abitti 2 exams. If the exam is run on an Abitti 2 server (version 1.0 or newer), the server must allow joining the exam via a web browser.  
The official YTL Abitti 2 application will be provided for upper secondary laptops once YTL releases it.


- 
The web browser used in Exam Mode has been updated. For Abitti 2 exams, the browser now runs in full-screen mode and supports functions such as brightness and volume controls from the Abitti 2 interface, as well as the use of all apps and materials.  
For other exams, the browser interface has been enhanced: the locked exam URL is shown, along with page navigation and zoom controls. 


- Update: VirtualBox updated to version 7.1.12

- 
Next-Exam is an open-source software for organizing locked exams. In Opinsys OS, Next-Exam has been integrated into Locked Exam Mode.  
There are two versions of the application, installed separately on devices:  
```Student version```, integrated into Exam Mode  
```Teacher version```, available for teacher accounts in the ```Teaching software``` section of the application menu


### Known Issues
- Random issues have been observed in the automatic startup of Abitti 1 exam servers. These may cause the Abitti VirtualBox server to start slowly or prevent the automatic startup altogether. The issue is under investigation. 

### Technical Changes

- Change: Automatic restart of exam servers is disabled by default. 
- Update: Minor fixes in ```puavo-disk-erase```, ```puavo-disk-clone``` and in device testing.
